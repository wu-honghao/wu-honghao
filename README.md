## 🚀 Featured Project — PermitMatch

**PermitMatch** is a full-stack web application designed to help software job seekers in Ireland compare their skills against job requirements, identify gaps, and track their progress across multiple job opportunities.

**Key features**
- AI-assisted job description extraction using Google Gemini, with user review before saving.
- Explainable skill matching with required and preferred requirements, including AND/OR logic.
- Skill gap analysis across multiple jobs.
- Saved analysis history with profile and job snapshots.
- JWT authentication, user-specific data access, and English/Chinese language support.

**Tech stack:** React, TypeScript, Ant Design, Node.js, Express, MongoDB, Gemini API, AWS.
